# Project_Lapkina_Solovjova_AnyLogic
Разработка адаптивной системы для управления сложным перекрестком средствами AnyLogic с модулями отслеживания пробок и снижения загрузки трафика
Студенты: Лапкина Е.В., Соловьева Д.А. (гр. 4618)

Описание проекта:
Проект представляет собой имитационную модель сложного перекрестка, разработанную в среде AnyLogic. Система предназначена для моделирования, анализа и оптимизации дорожного движения. Она объединяет два ключевых модуля:
1. Модуль отслеживания пробок: сбор, анализ и визуализация статистики о загруженности перекрестка, времени формирования и расформирования заторов.
2. Модуль снижения загрузки трафика: адаптивное управление режимами работы светофоров (обычный режим и режим затора) для уменьшения длины очередей и времени простоя транспорта.

Основной функционал:
- Моделирование дорожной сети: учет 6 перекрестков (2 регулируются светофорами, 4 знаками приоритета); поддержка 7 автобусных маршрутов с 4 остановками;
- Настройка потоков: регулировка интенсивности появления автомобилей (от 50 до 1000 ед./час) и автобусов (50 ед./час);
- Управление режимами: переключение между Обычным режимом и Режимом затора через графический интерфейс (CheckBox);
- Сбор статистики: подсчет количества проехавших машин (общий и по направлениям), отображение времени работы модели;
- Работа с БД: хранение и загрузка параметров дорог, маршрутов и статистики пробок через БД MySQL.

Файлы в репозитории:
- Moscov.alp — основной файл имитационной модели в среде AnyLogic;
- Moscov_Lapkina_48.zip — архив с проектом и сопутствующими файлами.

Как запустить проект:
1. Установите среду имитационного моделирования AnyLogic;
2. Скачайте файл Moscov.alp из этого репозитория;
3. Откройте файл через AnyLogic;
4. Запустите симуляцию;
5. Для работы с базой данных убедитесь, что настроено подключение к MySQL.

Результаты испытаний:
Были проведены избыточные испытания модели. Модель показала устойчивость при различных сценариях нагрузки. Адаптивная система светофорного регулирования успешно справляется с разгрузкой дорог при изменении интенсивности движения.
